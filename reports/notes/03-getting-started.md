# Getting Started

## OffCKB

Install:

```bash
npm install -g @offckb/cli
```

Run local Devnet:

```bash
offckb node
```

Reset local chain:

```bash
offckb clean
```

## RPC

Local development may expose CKB RPC through the local node / proxy configuration.

During Week 1, the working local RPC endpoint was:

```text
http://127.0.0.1:28114
```

## Networks

- Devnet: local development
- Testnet: public testing
- Mainnet: production
